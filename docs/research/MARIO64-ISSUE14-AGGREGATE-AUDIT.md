# Mario 64 object, enemy, and interaction aggregate audit (#14)

**Status:** GitHub issue #14 remains open. Its five original acceptance criteria remain unchanged and unchecked. Current child states were fetched from GitHub on 2026-10-27: #52, #53, #54, and #55 are closed; #56 is closed and #60 remains open. This report audits the evidence without changing those tracker boxes or claiming parent completion.

## Evidence boundaries

The target is the USA revision 0 ROM (SHA-256 `17CE077343C6133F8C9F2D6D6D9A4AB62C8CD2AA57C40AEA1F490B4C8BB21D91`). The dossiers combine canonical target-code/data analysis, pinned source-navigation evidence, and sanitized Project64 scalar observations. Static correspondence, structural script candidates, and runtime execution are separate evidence classes. Project64 samples use bounded read-only sampling and are not atomic snapshots. No ROM or RAM bytes, derived assets, save states, screenshots, raw captures, or private host paths are included here.
